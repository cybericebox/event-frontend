# Завантаження у фронтендах CyberICEBox

Один візуальний патерн діє на сайті події, головному сайті, сайті ID й адміністративному сайті. Кожен фронтенд має власну реалізацію компонента без спільного імпорту між застосунками.

## Вигляд

- Логотип стоїть у центрі області, яка завантажується. Для цілого екрана це центр екрана; для панелі чи форми — центр її області.
- Логотип плавно змінює прозорість і масштаб за цикл 1,8 с. За `prefers-reduced-motion: reduce` анімація вимкнена.
- На сайті події використовується логотип поточної події, якщо він доступний; інакше — знак платформи. Інші фронтенди використовують знак платформи.
- Звичайне одноетапне завантаження не має видимого підпису. Доступна назва стану залишається для допоміжних технологій.
- Видимий підпис (`message`) додається лише тоді, коли процес має змістовні послідовні етапи й текст пояснює поточний етап. Не використовувати загальне «Завантаження…» як видимий підпис.
- У маленьких кнопках та індикаторах дозавантаження залишається компактний стан без повноекранного логотипа.

## Місця застосування

| Фронтенд | Повний екран | Частина інтерфейсу |
| --- | --- | --- |
| Подія | `EventLoading full` | `EventLoading` |
| Головний сайт | `BrandLoading full` | `BrandLoading` |
| ID | `PageLoader` | `LoadingArea` |
| Адміністрування | `PageLoader` під час перевірки доступу | `LoadingArea` у робочій області |

Стан помилки чи втрати зв'язку не замінюється лоудером: він має власне пояснення та дію повтору.
